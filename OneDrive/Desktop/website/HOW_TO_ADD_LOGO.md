# How to Add Your College Logo

## Option 1: Add Logo Image File (Recommended)

1. **Save your college logo** as `logo.png` or `logo.jpg`
2. **Place the logo file** in the same folder as `index.html`
3. **Update index.html** - Change this line:
   ```html
   <img src="https://i.imgur.com/placeholder-logo.png" alt="AGM College Logo" class="college-logo"
   ```
   To:
   ```html
   <img src="logo.png" alt="AGM College Logo" class="college-logo"
   ```

## Option 2: Use Online Logo URL

If your logo is hosted online:
1. Copy the logo URL
2. Replace `https://i.imgur.com/placeholder-logo.png` with your logo URL

## Logo Specifications

For best results, your logo should be:
- **Format:** PNG (with transparent background) or JPG
- **Size:** 500x500 pixels or larger (square)
- **File size:** Under 500KB for fast loading

## Fallback Design

If no logo image is provided, the website shows:
- A beautiful circular badge with "AGMR" text
- Purple gradient background
- Same animations and effects

The design automatically switches to the fallback if the logo image fails to load!
